# Changelog

## [v2.0] - Próximamente
### Agregado
- E1: Validación de formulario de contacto con errores inline y sin librerías.
- E2: Consumo de API pública DummyJSON con renderizado dinámico de resultados.
- E3: Filtro y búsqueda dinámica en tiempo real sobre los datos obtenidos por fetch.
- E4: Modo oscuro persistente mediante localStorage.

### Mejorado
- Organización del código JavaScript en módulos ES6 independientes.
- Seguridad en la manipulación del DOM previniendo vulnerabilidades XSS mediante textContent y sanitización.

## [v1.0] - Entrega Inicial
- Sitio web estático con Bootstrap 5, CSS personalizado y eventos interactivos básicos.
